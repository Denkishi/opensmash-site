How online works

  • One server in Europe; relays through Epic Online Services as the fallback for every region.
  • Rollback netplay for fights, no port forwarding.
  • GSP ranked on the game's own online modes, per fighter and overall.
  • Discord sign-in, Rich Presence with Join, and an optional name on the leaderboard.

Install

  1. Download

    Get OpenSmash-Setup.exe from the latest release and run it. Pick a folder with about 60 GB free.

  2. Set up

    Point it at your own copy of the game (13.0.5), keys and firmware, then press Set up and build.

  3. Play

    Press Play in the launcher. Online is in Settings → Online.

Windows 10/11 64-bit, a Vulkan or Direct3D 11 GPU (Vulkan is the default), your own game dumped from your own Switch. Linux and macOS are experimental. Install guide · All releases
