WHAT'S IN THE BOX.

  • Native, not emulated

    The game's code translated to C once and compiled for x64. No interpreter, no JIT.

  • Vulkan by default

    Vulkan renderer, Direct3D 11 as a choice, Metal on Macs, a faster first start.

  • Online with rollback

    Rollback netplay for fights, room codes, LAN rooms, one lobby server.

  • Battle Arenas

    Find or create an arena by its code, right from the game's online menu.

  • GSP ranked

    GSP per fighter and a public leaderboard on this site.

  • Discord

    Sign in, Rich Presence with Join, an optional name on the board.

  • Mods and ARCropolis

    Launcher and mod manager, ARCropolis mods, Skyline plugins, a switch for each mod.

  • Controllers

    Dead zones, invert, GameCube adapters, keyboard keys, in-game settings (F1).

  • Ultrawide

    Ultrawide display support and a low-latency display mode.

  • Linux and macOS

    An OpenSmash launcher for Linux and macOS (experimental), Steam Deck friendly.

  • New fighters

    Fighters with files of their own, up to 16, even written as C++ source.

  • One-click installer

    Finds your game, keys and firmware and builds it for you; resumes if it stops.

THREE STEPS.

  1. Download

    Get OpenSmash.exe from the latest release and run it. Pick a folder with about 60 GB free.

  2. Set up

    Point it at your own copy of the game (13.0.5), keys and firmware, then press Set up and build.

  3. Play

    Press Play in the launcher. Online is in Settings → Online.

Windows 10/11 64-bit, a Vulkan or Direct3D 11 GPU, your own game dumped from your own Switch. Linux and macOS are experimental.
